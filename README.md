# ❤️ MatchNest

### From Casual Chats to Wedding Bells 💍

MatchNest is a modern matchmaking platform designed to help people build meaningful relationships. Whether users are looking for friendship, companionship, or a lifelong partner, MatchNest provides an engaging and secure environment with smart matching, real-time communication, and personalized recommendations.

---

## ✨ Features

### 👤 User Profiles

* Create and customize personal profiles
* Upload profile pictures
* Add interests, hobbies, and preferences
* Manage account settings

### ❤️ Smart Matching

* Discover compatible profiles
* Personalized recommendations based on preferences
* Match suggestions tailored to user interests

### 🔥 Swipe & Connect

* Like or pass profiles
* Mutual likes create a match
* Simple and engaging user experience

### 💬 Real-Time Chat

* Instant messaging between matched users
* Seamless communication experience
* Responsive chat interface

### 📹 Video Calling

* Secure one-on-one video conversations
* Better interaction before meeting in person

### 🔐 Secure Authentication

* User registration and login
* Protected routes and user sessions
* Secure account management

### 📱 Responsive Design

* Optimized for desktop, tablet, and mobile devices
* Modern and intuitive UI

---

## 🚀 Tech Stack

### Frontend

* React.js
* TypeScript
* Tailwind CSS
* React Router
* Axios

### Backend

* Spring Boot / Node.js (depending on implementation)
* REST APIs
* JWT Authentication

### Database

* MySQL / PostgreSQL

### Real-Time Communication

* WebSockets / Socket.IO
* WebRTC for Video Calls

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/matchnest.git
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
mvn spring-boot:run
```

or

```bash
npm install
npm start
```
